# EduTeacher — Білім мен болашақ алаңы

Мұғалімдерге арналған цифрлық платформа: ұлттық құндылықтар, комикстер, кері байланыс құралдары, цифрлық ойындар, дайын материалдар және аралық бақылау тапсырмалары.

Жаңа материалдар **әкімші панелі** арқылы қосылады (код өзгертудің қажеті жоқ). Мұғалімдерге тіркелу қажет емес — олар сайтқа еркін кіріп, материалдарды қарап, жүктей алады.

**Технологиялар:** React 18 · Vite · TypeScript · Tailwind CSS · Framer Motion · Lucide · React Router (HashRouter) · Supabase (Auth, Postgres, Storage)

---

## 1. Іске қосу

Компьютерде [Node.js](https://nodejs.org) (20 немесе одан жаңа) орнатылған болуы керек.

```bash
npm install
```

```bash
npm run dev
```

Сайт http://localhost:5173 мекенжайында ашылады. Supabase кілттері берілмесе, сайт бұрынғыдай кірістірілген материалдармен жұмыс істейді, ал әкімші панелі баптау нұсқаулығын көрсетеді.

## 2. Әкімші панелін баптау (бір рет)

### 2.1. Supabase жобасын ашу
1. https://supabase.com сайтында тіркеліп, **New project** басыңыз (Free тарифі жеткілікті).
2. Жоба ашылған соң **SQL Editor → New query** бөліміне [`supabase/schema.sql`](supabase/schema.sql) файлының мазмұнын толық қойып, **Run** басыңыз. Бұл:
   - `materials` кестесін,
   - тек әкімшіге жазуға рұқсат беретін RLS саясаттарын,
   - `materials` атты Storage bucket-ін (файлдарды бәрі жүктей алады, тек әкімші жүктеп сала алады) жасайды.

### 2.2. Өзіңізді әкімші ету
1. **Authentication → Users → Add user → Create new user**: email мен мықты құпиясөз енгізіп, **Auto Confirm User** белгілеңіз.
2. **SQL Editor**-да (email-ді өзіңіздікіне ауыстырып) іске қосыңыз:
   ```sql
   insert into public.admins (user_id)
   select id from auth.users where email = 'mnuraika04@gmail.com'
   on conflict do nothing;
   ```
3. **Authentication → Sign In / Providers → Email** бөлімінде **Allow new users to sign up** белгісін **өшіріңіз**. Сонда басқа ешкім тіркеле алмайды. (Тіркелсе де, `admins` кестесінде болмағандықтан ештеңе жариялай алмайды — бұны дерекқор деңгейінде RLS қорғайды.)

### 2.3. Кілттерді сайтқа қосу
**Project Settings → API** бөлімінен `Project URL` және `anon public` кілтін көшіріңіз.

- **Компьютерде тексеру үшін:** `.env.example` файлын `.env.local` деп көшіріп, мәндерді қойыңыз да, `npm run dev` қайта іске қосыңыз.
- **GitHub Pages үшін:** репозиторийде **Settings → Secrets and variables → Actions → New repository secret** арқылы екі secret қосыңыз: `VITE_SUPABASE_URL` және `VITE_SUPABASE_ANON_KEY`. Келесі жариялауда сайт панельге қосылады.

> `anon` кілті ашық болуға арналған — деректерді RLS саясаттары қорғайды. `service_role` кілтін ешқашан сайтқа қоспаңыз.

### 2.4. (Міндетті емес) Сілтемені нақты тексеру функциясы
Браузер басқа сайттың iframe-ге рұқсатын өзі тексере алмайды. Нақты тексеру үшін **Edge Functions → Deploy a new function → Via Editor** бөлімінде `check-embed` атымен функция ашып, [`supabase/functions/check-embed/index.ts`](supabase/functions/check-embed/index.ts) мазмұнын қойыңыз. Функция болмаса, панель белгілі сайттар тізімі бойынша анықтайды, ал «Сайт ішінде қарауға рұқсат» белгісін әрқашан қолмен өзгертуге болады.

## 3. Әкімші панелін қолдану

1. Сайттың жоғарғы оң жағындағы **профиль белгішесін** басып, **«Әкімші кіруі»** таңдаңыз (телефонда — мәзірдің төменгі жағында). Тікелей мекенжай: `…/#/admin`.
2. Email мен құпиясөз арқылы кіріңіз.
3. **«+ Материал қосу»** батырмасын басыңыз:
   - **Бөлім** — 6 бөлімнің бірі;
   - **Атауы**, **сипаттамасы**, **категориясы**, **сыныбы** (қажет болса), Дайын материалдар / Аралық бақылау үшін **пәні**, Аралық бақылау үшін **тоқсаны**;
   - **Материал түрі**: *Файл жүктеу*, *Сілтеме* немесе (Цифрлық ойындарда) *HTML ойын*;
   - **Мұқаба суреті** (міндетті емес);
   - **Жариялау**.
4. Материал бірден таңдалған бөлімде пайда болады. Тізімнен оны **өңдеуге**, **жасыруға** немесе **жоюға** болады.

**Қолдайтын файлдар:** Word (.doc, .docx), PowerPoint (.ppt, .pptx), PDF, Excel (.xls, .xlsx), JPG/JPEG, PNG, WEBP. Бір материалға бірнеше файл қосуға болады; файлдардың ретін ↑ ↓ батырмаларымен өзгертесіз. Бір файлдың шегі — 50 МБ (Supabase Free тарифінің шегі; жалпы көлем тарифке байланысты: Free — 1 ГБ).

### Мұғалімдер не көреді
| Материал | «Қарау» | «Жүктеу» |
|---|---|---|
| PDF | сайт ішінде ашылады | түпнұсқа файл |
| Суреттер | сайт ішінде; бірнеше сурет — бетпе-бет парақталатын viewer (← → пернелері, свайп) | әр файл бөлек |
| Word / PowerPoint / Excel | материалда PDF нұсқасы болса — алдымен сол көрсетіледі; әйтпесе Microsoft Office Online арқылы | түпнұсқа файл |
| Сілтеме | сайт рұқсат берсе — сайт ішінде; «Ашу» әрқашан жаңа қойындыда | — |
| HTML ойын | оқшауланған қауіпсіз терезеде | — |

**Кеңес:** Word/PowerPoint файлымен бірге оның PDF нұсқасын да жүктеңіз — алдын ала қарау әр құрылғыда дәл көрінеді.

### HTML ойындардың қауіпсіздігі
Жүктелген HTML файл сайттың өз доменінде емес, Supabase Storage-да сақталады және `sandbox` атрибуты бар iframe ішінде (`allow-same-origin`-сіз) іске қосылады. Сондықтан ойын коды сайттың деректеріне, әкімші сессиясына, cookie-ге немесе бет мазмұнына қол жеткізе алмайды. Ойын бір `.html` файлы түрінде болуы керек (суреттер мен скрипттер файлдың ішінде немесе сыртқы толық сілтемелер арқылы).

## 4. Жоба құрылымы

```
supabase/
  schema.sql                 кестелер, RLS, Storage саясаттары
  functions/check-embed/     (міндетті емес) iframe рұқсатын тексеру
src/
  data/                      кірістірілген (бұрынғы) мазмұн және тізімдер
    sections.ts              басты беттегі 6 бөлім
    resources.ts             ұлттық құндылықтар, кері байланыс, ойындар
    comics.ts                Heyzine комикстері және категориялар
    tools.ts                 цифрлық құралдар
    library.ts               сыныптар, пәндер, категориялар (әкімші формасы осыдан құрылады)
  lib/supabase.ts            Supabase клиенті
  services/
    materials.ts             жарияланған материалдарды оқу
    admin.ts                 жариялау, өңдеу, жою, файл жүктеу
    auth.tsx                 әкімші кіруі
  components/admin/          материал қосу формасы
  components/viewers.tsx     PDF/сурет/сілтеме/HTML көрсеткіштер
  pages/Admin.tsx            әкімші панелі
  pages/MaterialViewer.tsx   материалды қарау беті (/#/view/<id>)
```

Жаңа пән немесе категория ұсыныстарын `src/data/library.ts` ішінде өзгертуге болады; әкімші формасында тізімде жоқ мәнді қолмен жазуға да болады.

## 5. GitHub Pages-ке жариялау

Сайт `HashRouter` және салыстырмалы `base: './'` қолданады, сондықтан репозиторий атауы қандай болса да ішкі беттер (мысалы `…/#/comics`) тікелей ашылады.

### А нұсқасы — GitHub Actions (ұсынылады)

1. GitHub-та жаңа репозиторий ашыңыз (мысалы `eduteacher`).
2. Жоба файлдарын репозиторийге жүктеңіз (`node_modules`, `dist` және `.env.local`-сыз). Git орнатылған болса:

   ```bash
   git init
   ```
   ```bash
   git add .
   ```
   ```bash
   git commit -m "EduTeacher"
   ```
   ```bash
   git branch -M main
   ```
   ```bash
   git remote add origin https://github.com/<ПАЙДАЛАНУШЫ>/eduteacher.git
   ```
   ```bash
   git push -u origin main
   ```
3. **Settings → Secrets and variables → Actions** бөлімінде `VITE_SUPABASE_URL` және `VITE_SUPABASE_ANON_KEY` secret-терін қосыңыз (2.3-бөлім).
4. **Settings → Pages → Build and deployment → Source: GitHub Actions** таңдаңыз.
5. `main` тармағына әр push жасалғанда сайт автоматты түрде жиналып, жарияланады. Мекенжайы: `https://<ПАЙДАЛАНУШЫ>.github.io/eduteacher/`

Материалдарды панель арқылы қосқанда сайтты қайта жариялаудың қажеті **жоқ** — олар Supabase-тан бірден оқылады.

### Б нұсқасы — `gh-pages` пакеті арқылы

`.env.local` файлы толтырылған және репозиторий git арқылы қосылған болса:

```bash
npm run deploy
```

Содан кейін **Settings → Pages → Source: Deploy from a branch → gh-pages** таңдаңыз.

### Әлеуметтік желі алдын ала көрінісі
`index.html` ішіндегі `og:image` мәнін сайт жарияланғаннан кейін толық мекенжайға ауыстырыңыз, мысалы `https://<ПАЙДАЛАНУШЫ>.github.io/eduteacher/images/hero.webp`.

## 6. Мүмкіндіктер

- Әкімші панелі: 6 бөлімге материал қосу, өңдеу, жасыру, жою; бірнеше файл, мұқаба, сілтеме тексеру
- Supabase Auth (email + құпиясөз), RLS және Storage саясаттары арқылы қорғалған жазу құқығы
- Әмбебап қарау беті: PDF, суреттер (парақтау), Office құжаттары, сілтемелер, оқшауланған HTML ойындар
- Жалпы іздеу (`Ctrl + K` немесе `/`): кірістірілген және жарияланған барлық материалдар
- Комикстер: категория бойынша сүзгі, іздеу, сайт ішінде оқу, толық экран
- Дайын материалдар / Аралық бақылау: сынып, пән, материал түрі, формат және тоқсан бойынша сүзгі
- Loading / empty / error күйлері, lazy loading, code splitting, клавиатурамен басқару, `prefers-reduced-motion`
- Барлық сыртқы сілтемелер `target="_blank" rel="noopener noreferrer"` арқылы ашылады
